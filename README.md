# quiz-game
A simple Python quiz game with questions and score calculation.

## Features

- Asks 5 quiz questions
- Checks the user's answers
- Calculates the final score
- Shows correct and wrong answers

## Concepts Used

- Python
- Variables
- Input and Output
- If-Else Statements
- String Methods
